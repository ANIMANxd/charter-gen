Formulas, worked example & learning outcomes

MetricFormulaReading
Cost VarianceCV = EV − AC> 0 under budget · < 0 over budget
Schedule VarianceSV = EV − PV> 0 ahead · < 0 behind schedule
CPI / SPICPI = EV/AC · SPI = EV/PV> 1 good · < 1 poor · = 1 on plan
EACBAC/CPI · AC+(BAC−EV) · AC+(BAC−EV)/(CPI·SPI)Expected total cost under each assumption
ETC / VAC / TCPIETC=EAC−AC · VAC=BAC−EAC · TCPI=(BAC−EV)/(BAC−AC)Left to spend · overrun · efficiency needed
PDF worked example: PV = 100, EV = 80, AC = 90 → CV = −10 (over budget) · SV = −20 (behind) · CPI = 0.89 (inefficient) · SPI = 0.8 (delayed). Sprint 1 above reproduces it exactly — press “Load PDF example” any time to restore it.
Learning outcomes: variances reveal project health (§1) · indexes measure efficiency and schedule adherence (§2) · EAC/ETC practise predictive cost management (§3) · regression shows how AI improves accuracy in dynamic projects (§4) · anomaly flags show how AI catches risk before it escalates (§5).
